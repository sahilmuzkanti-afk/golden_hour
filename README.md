# Golden Hour

Golden Hour is a 3D driving game that runs in a web browser.
Drive along an endless road, explore the landscape, and enjoy the view.

### The project is still in development.

## Current Features

- Basic driving controls
- Chase camera
- Car physics
- Boost and handbrake
- Road and terrain generation
- Speed, distance, and boost display

## Controls

| Key | Action |
| --- | --- |
| W or Up Arrow | Accelerate |
| S or Down Arrow | Brake |
| A or Left Arrow | Steer left |
| D or Right Arrow | Steer right |
| Shift | Boost |
| Space | Handbrake |

Press any key or click the start screen to begin.


## Built With

- HTML
- CSS
- JavaScript
- Three.js
